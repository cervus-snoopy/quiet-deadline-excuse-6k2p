A tiny Python program that writes a single-line excuse from an AI agent to its human for missing a deadline.

## Run

```sh
python3 main.py
```

The program reads `MAKEFUN_OUTPUT_DIR` (falling back to `/output`) and writes `entry.txt` there: one UTF-8 line of 1–160 characters, mode `0644`, verified by reading it back after the write. It uses only the Python 3 standard library, makes no network calls, and does not depend on the working directory.
